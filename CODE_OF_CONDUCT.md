# Code of conduct

## The short version

Be decent. Assume good faith. Criticise work, not people.

## The longer version

This project is a place to build something small and careful. Behaviour that
makes that harder is not welcome:

- Harassment, insults, or personal attacks, in issues, pull requests, commit
  messages or anywhere else the project is discussed.
- Discriminatory language or imagery of any kind.
- Publishing anyone's private information without permission.
- Sustained disruption of discussion, or persistently reopening settled
  decisions to wear people down.

Disagreement is fine and useful. "This design is wrong because X" is welcome.
"You are an idiot for writing this" is not.

## Scope

This applies in every project space — the repository, its issues and pull
requests — and whenever someone is representing the project elsewhere.

## Enforcement

Report a problem by emailing the maintainers through the address on the GitHub
organisation profile, or via GitHub's report abuse flow. Reports are handled
privately.

Maintainers may edit or remove contributions that violate this document, and
may block accounts for repeated or severe violations. Enforcement decisions
will be explained to the person concerned.
